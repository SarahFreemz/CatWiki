## CatWiki

Welcome to CatWiki, a bestiary documenting the creatures, humans, and notable behaviors of the Fremont household. CatWiki is a Wikepedia-style repository of information documenting my pet cats (read: my sons), built with Docsify and hosted on GitHub Pages.

[Click here for Live Site](https://sarahfreemz.github.io/CatWiki/#/)

### About

I built this site to compile the deep lore my family has built up around my beautiful cats, both as a creative project and as a way to tell the world about the wonderful little creatures that live in my house.

### Built with

- Docsify
- Markdown
- HTML/CSS
- GitHub Pages
- GitHub Copilot
